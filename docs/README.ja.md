Buckle は、システムツール、言語を指定したブラウザ起動、Finder の日常操作をまとめた macOS ネイティブのメニューバーアプリです。バックグラウンドで動作し、Dock にアイコンは表示しません。

**[macOS 版をダウンロード](https://github.com/SlippinDylan/Buckle/releases/latest)** · [開発ガイド](development.md)

> [!NOTE]
> この README は現在のソースコードの機能を説明しています。配布版の変更内容と制限は、各バージョンのリリースノートを確認してください。

## インストールと初回設定

**macOS 15 以降**の Apple Silicon または Intel Mac が必要です。CI のビルド対象は Universal 2 です。

1. [GitHub の最新リリース](https://github.com/SlippinDylan/Buckle/releases/latest)の **Assets** から `Buckle-<version>.dmg` をダウンロードします。ソースコードのアーカイブは開発用で、インストーラではありません。
2. 更新時は、起動中の Buckle のメニューから「終了」を選び、終了するまで待ちます。DMG を開き、`Buckle.app` を「アプリケーション」にドラッグし、必要に応じて旧版を置き換えます。
3. `/Applications/Buckle.app` を開きます。Buckle はメニューバーに表示され、Dock アイコンは表示しません。インストールしたコピーは1つだけにしてください。
4. メニューバーからツールを使い、Finder の右クリック機能を有効にします。4つの Finder 機能は初回はすべて無効で、以降は選択内容が保存されます。
5. 「設定 → アクセス権」で Finder 拡張機能を有効にし、必要な権限を付与します。状態は自動更新され、緑の文字とチェックマークは許可済みまたは有効であることを示します。

設定ガイドをまだ閉じたり完了したりしていない場合、通常の起動時に一度だけ表示されます。既存ユーザーにも表示されますが、現在の設定は保持されます。ガイドではメニューバーの使い方、Finder の操作と必要な権限、ログイン時の起動、自動アップデート確認を設定できます。変更はすぐに保存され、4 つの Finder 操作は自分で選ぶまでオフのままです。権限を許可せずに進むこともできます。ウインドウを閉じると、再起動やアップデート後も自動では表示されません。新規ユーザーがアップデート設定をスキップした場合、自動確認はオフのままです。既存の更新設定は保持され、更新対応ビルドでは手動確認も引き続き利用できます。 最後に同じウインドウに設定完了ページが表示され、利用開始ボタンから Buckle のメニューを開けます。 権限は機能の切り替えより前の独立したページで確認でき、許可せずに進むこともできます。

> [!IMPORTANT]
> ビルドは ad-hoc 署名で、公証されていません。ダウンロードしたビルドはシステム設定で実行の許可が必要な場合があります。更新後に権限の再許可が必要になる場合もあります。

Homebrew でのインストールはまだ利用できません。[共通 Tap](https://github.com/SlippinDylan/homebrew-tap) で Buckle Cask が公開されるまでは DMG を使用してください。

## アンインストールと再インストール

メニューから Buckle を終了し、終了を待ってから `Buckle.app` をゴミ箱に移動します。App の削除だけでは設定とガイドの記録が残るため、上書きや再インストールでガイドが再表示されることはありません。

再インストール後にガイドをもう一度表示するには、Buckle の終了後にターミナルで次のコマンドも実行します。

```bash
defaults delete studio.slippindylan.Buckle onboarding.dismissed
```

このコマンドはガイドを閉じた記録のみを削除し、ほかの設定、Finder のデータ、システム権限は保持します。記録が存在しない場合は削除不要です。再インストール後、Buckle を手動で起動するとガイドが一度表示されます。通常のアップデートでは実行しないでください。

## 設定

「設定 → 一般」でログイン時の起動とアプリの言語を設定します。既定では macOS に従います。英語、簡体字中国語、繁体字中国語、日本語、韓国語、ドイツ語、フランス語、スペイン語を選択できます。言語の変更後は Buckle を再起動してください。

「設定 → マウスリセット」でアプリを追加・削除し、再度開くまでの待機時間を0〜60秒で設定できます。デフォルトは3秒です。変更は自動保存され、リセット中は編集できません。

## 使用前の注意

- **メモリウインドウ：** macOS LowMemoryPanel を手動で開きます。通常のメモリ使用量でも利用できます。内蔵のメモリ不足メッセージは Buckle の診断ではありません。非公開のシステムデバッグ経路を使い、対象のメモリ警告ウインドウを確認して一時設定を復元します。確認できなければエラーを報告します。互換性は macOS の各バージョンで実機確認が必要です。アクセシビリティと System Events のオートメーション権限が必要で、バックグラウンド監視は行いません。
- **マウスのリセット：**「設定 → マウスリセット」でアプリのリストを管理できます。初期リストは Moom、MonitorControl、BetterMouse、iShot Pro です。実行のたびに、リスト内で実行中のアプリを終了し、macOS の共有環境設定サービスとシステム権限サービスを更新してから、アプリを再度開きます。実行中だったアプリのみ再度開きます。サービスの更新は他のアプリに一時的に影響する場合があり、管理者認証が必要です。アンインストール済みのアプリはスキップし、リストが空でもサービスを更新します。復元待ちのリストは保存されます。操作が中断された場合、次回起動時にアプリを再度開くか確認し、「後で」を選ぶと記録を保持します。
- **システムメニューバーの再起動：** 現在のユーザーの SystemUIServer を sudo なしで再起動します。他のアプリが管理するアイコンの問題は直らない場合があります。
- **ブラウザのプロファイル：** ブラウザの既存データと保存済みのログイン状態を使い、別のプロファイルは作成しません。複数のプロファイルの選択はブラウザ自身の動作に従います。起動言語を切り替える前にブラウザを終了してください。すでに起動している場合、Buckle は通知のみを表示します。日本語での起動時は元のスクリプトと同様にブラウザのプロセスに東京のタイムゾーンを指定し、他の言語ではシステムのタイムゾーンを維持します。macOS の設定や IP アドレスは変更せず、サイトの言語や地域書式は保証しません。タイムゾーンの動作確認は Chrome Beta のみで実施しています。
- **Finder：** パスのコピーは機能拡張内でプレーンテキストとして行い、複数のパスは改行で区切ります。他の操作は必要に応じて Buckle を起動します。移動する場合は Finder でファイルをコピーし、移動先フォルダまたはその背景を右クリックします。Buckle が Finder で移動先を開き、標準の移動コマンドを実行します。アクセシビリティと Finder・System Events のオートメーション権限が必要です。進捗、同名項目、取り消しは Finder が処理するため、結果はシステムのダイアログで確認してください。Buckle は転送完了を待ちません。メニュー位置は Finder が決めます。Buckle 独自の Finder メニュー項目は Buckle の再起動後にアプリの言語に従い、ネイティブの AirDrop 名はシステムに従います。 権限ページでは、Finder と System Events のオートメーション権限を個別に表示します。 別のコマンドの誤実行を防ぐため、Finder または全体のメニューショートカットがカスタマイズされている場合、自動移動は実行しません。Finder で直接操作してください。
- **AirDrop:** システムの共有画面を開き、転送の完了は待ちません。同時に開ける AirDrop セッションは1つですが、ほかの Finder 操作は利用できます。Buckle は AirDrop のために終了を待機しません。共有画面の使用中は Buckle を起動したままにしてください。
- **更新：** Sparkle を統合しています。手動確認は「設定 → このアプリについて」、自動確認は「一般」にあります。開発、CI 検証、テストパッケージでは更新を無効にし、正式な Release ビルドで有効にします。パッケージ作成が有効な場合、main の完全な CI ビルド成功後に未公開のバージョンを自動でパッケージ化・公開し、署名済み更新フィードと Homebrew Cask を同期します。ドキュメントや補助ファイルのみの変更は公開しません。オンライン更新には、公開済みのインストーラと署名済みフィードが必要です。

## ソースからビルド

<details>
<summary>ソースからのビルドと開発手順を表示</summary>

Xcode 26 以降、Node.js、Python 3 が必要です。Debug ビルドに Apple 開発者アカウントは不要です。

```bash
git clone https://github.com/SlippinDylan/Buckle.git
cd Buckle
bash Scripts/check.sh
bash Scripts/build.sh Debug
```

ビルド後は、用途に応じて以下のどちらかを選んでください。

### 日常利用向けにインストール

実行中の Buckle のメニューバーメニューで「終了」を選び、終了するまで待ちます。Finder で `build/DerivedData/Build/Products/Debug/` 内の `Buckle.app` 全体を `/Applications` に移動します。既存のアプリを置き換える場合も、先に終了してください。`/Applications/Buckle.app` を開き、インストールするコピーは 1 つにしてください。

### 開発用にビルドを実行

実行中の Buckle を「終了」で閉じ、終了を待ってから下記のコマンドを実行してください。または、既存のアプリを終了してから `Buckle.xcodeproj` を開き、`Buckle` scheme を Debug で実行します。Buckle は同時に 1 つだけ実行できます。別のコピーが実行中の場合、新しいプロセスは終了します。開発中はテスト対象のビルドを使い、インストール済みのコピーを同時に開かないでください。

```bash
open build/DerivedData/Build/Products/Debug/Buckle.app
```

</details>
